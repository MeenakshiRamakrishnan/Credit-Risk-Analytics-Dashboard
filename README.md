# Credit Risk Analytics Dashboard

## Project Overview
This project analyzes customer credit risk using Excel dashboards, Pivot Tables, Pivot Charts, and Slicers.

## Dashboard Features
- Total Customers KPI
- Total Loan Amount KPI
- Average Credit Score KPI
- Default Customers KPI
- Default Rate KPI
- High Risk Customers KPI
- Loan Type Distribution
- Risk Category Breakdown
- Loan Disbursement Trend
- Loan Portfolio Status Analysis
- Default vs Non-Default Analysis

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

## Key Insights
- Home Loans contribute 35%
- High Risk Customers: 34.5%
- Default Rate: 8.3%
- Peak Loan Disbursement in April
- Personal Loans have the highest default count
